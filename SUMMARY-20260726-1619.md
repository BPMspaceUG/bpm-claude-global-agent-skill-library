`#101` was marked `tested-success` while its claimed artifacts were absent from `main`. The first Codex gate concluded the state was unsupported — **and I reported that as fabrication, which was wrong.**

> This repo pushes directly to main and **never merges PRs**. An agent opened one anyway. Nobody merged it. The milestone was advanced against a branch — true of the branch, false of the product. Every individual step was honest, and `main` still lacks a security control everyone believes shipped.

**Not merged tonight.** It touches the two command files this run already changed on `main`, and merging a stale unreviewed branch at the end of an unattended run risks reverting gate-approved work. Recommendation: rebase onto current `main`, re-run the gates, land **directly on main**, close #110 without merging.
